# Milestone 2: who owns what

Read `CLAUDE.md` and `docs/ARCHITECTURE.md` first. The contract is `packages/shared/protocol.js` (v2): every M2 method,
event and type is already in it. **Don't change it.** If you need something it lacks, work around it and say so in your
final report. The lead changes the contract.

Each track works in its own git worktree on its own branch (`m2-<track>`), made from `m2`. Stay inside your files.
Where you must touch a shared file, keep the change small and say so in your report.

## Shared groundwork (lead)

| File | What |
|---|---|
| `packages/shared/protocol.js` | Contract v2 |
| `packages/core/src/server.js` | Routing for every method (async handlers allowed: return a Promise) |
| `packages/core/src/core.js` | Roles (one Main per space), `agents.update`, `agents.restart`, `core.shutdown` |
| `packages/app/src/renderer/context.js` | `ViewContext` / `View`: what views get from app.js |
| `packages/app/src/renderer/app.js` | View switch (`S.view`), `ctx`, keyboard. **Layouts** may edit the tab / pane / terminal parts |
| `packages/app/src/renderer/roles.js`, `components/roles.css` | Role list (copy of protocol ROLES) and `roleBadge(agent)` |
| `packages/app/src/main/main.js`, `preload.js` | Wires one module per track; the bridge (`window.cc`) already has every M2 call |

Views: `createXView(ctx)` returns `{ el, update(), show?(), hide?() }`. `update()` runs on every render while shown.
Shortcuts (already wired): `Ctrl+Shift+T/G/B/A/L/D` = Terminals / Grid / Board / Inbox / Library / Dashboards,
`Ctrl+,` = Settings, `F2` = edit the focused agent. Plain `Ctrl+B`, `Ctrl+L`, `Ctrl+I` belong to the terminal.

## Every track

- Plain JS, `// @ts-check`, Windows first (see CLAUDE.md). No new runtime dependencies without the lead.
- Tests for every new behaviour: core tests with the fake Claude and `CC_HOME`, e2e against the mock core
  (`renderer/dev/mock-core.js`). Never call the real Claude, never touch the real `~/.claude` in tests (point
  `CLAUDE_CONFIG_DIR` / `HOME` at a temp dir).
- Before you finish: `npm test` and `xvfb-run -a npm run test:e2e` pass. Commit on your branch in small commits. Don't push.
- Final report: what you built, files touched outside your list, contract gaps, anything left undone.
